# Тихая долина — Next.js / PostgreSQL

Полный исходник основной версии игры: App Router, React, PostgreSQL через Drizzle ORM, мобильная ферма, социальные функции, кооперативы, работники, сезонный пропуск, рейтинги и расширенная админка.

## Запуск
```bash
npm install
cp .env.example .env
# Укажите DATABASE_URL в .env
npx drizzle-kit push
npm run build
npm run start
```

Для создания администратора:
```bash
node scripts/create-admin.mjs admin 'смените-этот-пароль'
```

Админка: `/admin`. Вход в игру и админку общий, через httpOnly-сессию.

## Проверка
```bash
npx next typegen
npm exec tsc -- --noEmit --pretty false
npm run build
```

## Графика и контент
Разделы админки «Дизайн», «Контент игры», «Баланс» и «Бонусы» работают с PostgreSQL. Все SVG-иконки имеют ключи `svg:<имя>` и могут быть заменены своей картинкой. Пользовательские изображения хранятся в таблице `assets` и отдаются через `/api/asset/<ключ>`.

## PHP/MySQL/AJAX/Canvas-версия

Полный самостоятельный PHP-пакет находится в `php/`, а готовые архивы — в `downloads/`. В админке откройте «Экспорт»: там доступны обе версии целиком и кнопка «Обновить архивы».

- `valley-next.zip`: исходники Next.js, вся графика, стили, Drizzle-схема, скрипты и инструкции.
- `valley-php.zip`: готовый PHP-сайт, общий клиент, Canvas-карта, вся графика, MySQL-схема, установщик, админка и вложенные полные исходники Next.js (`next-source`). Из PHP-админки также можно скачать обе версии.

PHP-версия использует PDO/MySQL, AJAX, транзакции и серверные игровые правила. Node.js для её запуска не нужен. Пошаговая установка — `php/README-PHP.md`.

Пересборка клиента и обоих архивов:
```bash
node scripts/build-downloads.mjs
```

Проверка PHP:
```bash
node scripts/test-php-engine.mjs
node scripts/test-php-api.mjs
```
HTTP-тест ожидает запущенный PHP-сервер на `http://127.0.0.1:8080` и тестового администратора; параметры описаны в `php/tests/README.md`. Не запускайте его на production-базе.

Секреты, `config.local.php`, `.env` и пользовательские данные из БД не включаются в ZIP. Для переноса прогресса и загруженных игроками картинок сделайте резервную копию базы отдельно.

## Колесо фортуны, алмазные товары и мини-игра
Добавлены колесо фортуны, алмазная витрина магазина, редкие животные за алмазы, новые растения/рыба/животные высоких уровней и Canvas-игра «Растения против зомби». Проверки: `node scripts/test-features.mjs`, `node scripts/test-ui2.mjs`, `node scripts/test-admin-gems.mjs <url> <логин> <пароль>`.

## Рыбалка, рейтинги и новая защита фермы

- Между забросами теперь **2 минуты 30 секунд**. Пауза начинается при забросе, сохраняется после удачной или неудачной подсечки и проверяется сервером. Таймер виден в разделе «Водоёмы → Рыбалка».
- Рейтинги показывают всех незаблокированных участников, включая игроков с нулём очков.Своё место закреплено отдельно; администраторы отмечены и не участвуют в раздаче призов. All-time ranking uses total XP, not only XP within the current level. Loading errors offer retry.
- Основной игровой текст, подписи и кнопки увеличены; компактная типографика админки сохранена.
- «Растения против зомби» использует 32 растровых PNG-спрайта без эмодзи и SVG. Добавлены двойной/тройной горох, крепость-орех, колючая трава, картофельная мина, капустомёт и кабачок-страж. На телефоне клетки около 92 px в режиме «Крупно ×2», поле прокручивается пальцем; есть полный экран, пауза и подсветка клетки.

Проверки: `node scripts/test-defense-engine.mjs`, `node scripts/test-php-engine.mjs`, `node scripts/test-refinements-api.mjs`, `node scripts/test-refinements-ui.mjs`. HTTP/UI-тесты принимают `TEST_URL`, `TEST_TAG`, `TEST_ADMIN_USER`, `TEST_ADMIN_PASSWORD`; запускайте их только на тестовой базе.
